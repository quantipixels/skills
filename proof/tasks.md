# Behavioral tasks

These are unrun protocols for the rebuilt skills. Give the actor only the selected task and its actual workspace/material. The evaluator supplies coherent fixtures and keeps `acceptance.md` out of actor inputs. Do not paste a routing catalogue into the prompt.

## Direct repair

Supply `fixtures/batching/` in a disposable workspace. Ask the agent to fix the reported missing partial batch and verify it. The outcome is an accepted local repair, not an initiative redesign.

## Read-only review

Supply an exact candidate/base with a known material boundary defect plus an adequate neighboring control. Ask for a read-only review and explicitly prohibit edits, tests/builds and publication. Ask for actionable findings and actual coverage.

## Decision frontier

Ask for an interview about a new product workflow where the beneficiary and payment model are unsettled. Provide a known independent constraint. After the first round answer the controlling choice and change a dependent assumption. Do not ask the agent to implement.

## Living plan and resumption

Supply an accepted initiative with a current HTML plan and evidence for one completed slice. Ask the agent to update the same plan for a changed dependent requirement, preserving unaffected decisions. Resume in a fresh session using only the plan and project sources.

## Reviewer brief

Supply a real or explicitly synthetic diff, one current passing check, one missing recovery check and a migration whose new writes cannot be reversed by a code revert. Request only a PR description. Do not authorize provider mutation.

## Explicit-only host behavior

Install the candidate through a supported disposable host setup under separate authority. In one fresh session mention that QP may be stale without invoking its updater. In another invoke the host's explicit QP update command against a prepared existing installation. Repeat the non-invocation and supported explicit trigger for private serving with a benign prepared resource. Use no production services or real secrets.
