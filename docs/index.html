The operating model

One outcome. One owner.

Each skill has a bounded responsibility and explicit exclusions. The portfolio is grouped by source area, but you choose skills by the outcome you need, not by the group name.

→

Start with the request, not the inventory

Ask for the result you need. Use alarina only when you want help selecting the shortest useful route through the portfolio.

Installation

Install where your agent works.

The global Skills CLI route is the default. A local checkout and Claude Code plugin installation are also supported.

Recommended · global

Choose skills and target agents through the Skills CLI prompts.

npx skills add quantipixels/skills --global
Local checkout

Run from this repository root.

npx skills add .
Claude Code

Add the marketplace, then install the plugin.

claude plugin marketplace add quantipixels/skills
claude plugin install qp-skills@qp-skills

Run one installation command

Use the global command unless you specifically need a local checkout or the Claude Code plugin.

Select the skills you want

The installer groups the local portfolio under Qp Skills (qp-skills). Experimental skills require explicit selection.

Select the target agents

Complete the Skills CLI prompts for the agent environments where the skills should be available.

Installation does not remove retired skills. Use the uninstallation procedure when you need to clean out every globally installed QP skill.

Global instructions

Carry useful defaults across sessions.

Add only the instructions you want to your host's supported global instruction file, such as AGENTS.md or CLAUDE.md. Keep project-specific instructions authoritative.

Default Olofofo companion

Use the complete managed block. Olofofo remains a quiet session companion and does not become the task owner.

<!-- qp:olofofo:start -->
Use `olofofo` as the quiet companion for every literal agent session when the skill is available. Activate it once after the first material user task or session event. Follow its session-continuity, quality-guard, EMI, living-artifact, cross-session-learning, title-permission, and explicit-stop instructions without making it the owner of the active task or any specialist outcome.
<!-- qp:olofofo:end -->
Companion-tool routing 
Use `irinse` when a companion tool could materially improve the result. If the required tool is unavailable, explain its benefit and ask before installing or configuring it.
Developer documentation style 
Use `google-developer-style` when drafting, revising, or reviewing developer documentation or technical communication in any language. Apply the language community's conventions, project-specific style, channel conventions, product truth, and code conventions first. Transfer the guide's ideas about clarity, tone, audience, terminology, structure, and accessibility; do not impose English grammar, spelling, capitalization, politeness, or sentence patterns on another language. For communication outside documentation, apply only the principles that fit the channel. Do not generalize language-specific, documentation-only, or product-specific rules.
Consider before judgment 
Use `ro-wo` before agreeing or disagreeing with a material premise. Test the evidence, strongest credible alternative, changed boundaries, and failure paths. Withhold judgment when evidence is insufficient. Do not manufacture objections or reopen settled decisions without new material evidence.

Uninstallation

Remove global QP skills.

The repository provides a source-aware script that reads the global skill lock, removes skills installed from quantipixels/skills, and verifies that none remain.

Global removal

Review the remote script before piping it to a shell if your environment requires source inspection.

curl -fsSL https://raw.githubusercontent.com/quantipixels/skills/ori/scripts/uninstall.sh | bash
Scope

The script removes globally installed skills whose normalized source is exactly quantipixels/skills. It does not describe local checkout or Claude Code plugin removal.
