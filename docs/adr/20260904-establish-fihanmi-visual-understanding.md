# Establish visual understanding as Fihànmí

Status: Accepted

`fihanmi` is a thin Productivity owner and reusable steering contract for one directly selectable outcome: make supplied or current material visually understandable with the smallest faithful representation.

## Boundary

Fihànmí follows the same lightweight shape as the demonstrated `show-me` pattern: pseudocode for logic, call/component/responsibility trees for structure, shaped diffs for change, Mermaid for relationships that benefit from two dimensions, and a complete block/tree/flow when omitted context would hide order or ownership.

For direct visual-understanding requests it may inspect supplied/current evidence and derive the observed or inferred structure needed for the visual. It does not originate normative intent, unsupported causality, desired ownership, decisions, recommendations, verdicts, readiness, or priorities. When another skill already established the meaning, that result remains authoritative.

The adaptation adds only general fidelity guards that apply across visual subjects: preserve exact wording when it is evidence, distinguish observed/inferred/proposed/illustrative status when material, do not invent missing relationships for symmetry, and keep before/after views comparable. Domain-specific diagnosis does not belong in the base grammar merely because one visual form could expose it.

`salaye` owns newcomer-oriented plain-language explanation, `html-artifact` owns substantial standalone browser information projections, and `slides` owns presentation/deck results. These are adjacent result boundaries rather than mandatory escalation stages.

## Why public

“Show me”, “visualise this”, “show the call path”, and “show what changed” are natural direct selections whose result is independently useful across domains. The public identity saves users from restating the same compact representation instructions without creating another semantic-analysis owner.

The skill stays intentionally small: one behavior-bearing instruction surface with concrete representation examples, no renderer catalogue, scripts, persistence layer, routing machinery, or independent lifecycle.

## Placement

Fihànmí lives in Productivity because visual legibility is itself a stable directly selectable result. Experimental status is not a compulsory staging area for every new skill; future real-use evidence can still justify narrowing, folding, replacing, or removing it.

## Reuse

Fihànmí is the canonical low-cost visual grammar. Another owner may use it internally when a visual supports that owner's result without transferring semantic ownership or creating a visible pipeline. Owner-local guidance should add only result-specific concerns that genuinely remain outside the generic visual contract.

## Existing Fihàn name

The prior `fihan` private-serving owner is renamed `pese` (Pèsè, “provide/make available”) without changing its direct-invocation, transport, security, proof, or revocation semantics. This frees Fihànmí for the visually natural “show me” meaning and removes a confusing near-name collision between unrelated outcomes.
