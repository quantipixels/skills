# Separate Ko Skill authority by mode

Status: Superseded by [Unify the Ko Skill workflow](20260818-unify-ko-skill-workflow.md).

Ko Skill uses `author` to create or revise one skill, `validate` to assess one exact candidate read-only, and `audit` to assess a bounded portfolio read-only. These modes replace `one-skill` and `portfolio-audit`. Ko Skill remains the authoring owner; adjacent specialists can supply evidence or own related artifacts but do not replace it for skill creation, revision, or validation.

The previous one-skill mode combined mutation and validation, so an exact-candidate validation could appear to authorize repairs. The longer portfolio name repeated context already supplied by Ko Skill. Separate short verbs make mutation authority explicit while all modes retain the same capability, integration, proof, and state vocabulary.
