# Unify the Ko Skill workflow

Ko Skill creates, revises, or validates one skill through one shared workflow. The requested operation and explicit mutation authority determine whether files may change; validation remains read-only. A bounded portfolio audit loads its conditional reference and remains read-only without becoming a public mode.

The separate `author`, `validate`, and `audit` modes made authority visible but split the common contract. The validation branch lost capability mapping, cross-resource semantic closure, and explicit behavioral proof, allowing structural success to appear sufficient. One workflow keeps those gates common while preserving mutation authority as an independent field.
