## Method

These were disposable fresh-goal tabletop runs against the proposed Experimental skill contracts. Each run began from the raw goal shown below and checked whether the candidate instructions selected the intended boundary without relying on the former Akọ̀wé stack catalogue or Pẹpẹyẹ playbooks.

This is forward behavioural evidence, not a persistent prompt-evaluation suite. It does not prove host-specific skill discovery, browser automation, external research availability, or production implementation quality. Repository CI remains the structural/package proof.

## Findings

- Akọ̀wé's useful invariant is adaptive synthesis, not possession of an internal code corpus.
- The dynamic route remains bounded because expertise needs are derived from touched mechanisms and material failure paths.
- The proportionality gate closes the main overengineering failure mode without requiring a generic best-practice catalogue.
- Dogfood, Ideate, Prototype, and Root Cause retain independently useful outcomes after removing rigid or over-broad rules.
- Pẹpẹyẹ remains independently testable only as supervision. Its former playbook catalogue and universal lifecycle duplicated stable owners.
- No experiment required a new script, schema, prompt harness, or provider-specific runtime.

## Remaining evidence gaps

- Run Akọ̀wé in hosts that expose different skill-discovery surfaces to verify portability of description/metadata inspection.
- Exercise Dogfood with a real browser candidate before considering promotion.
- Exercise Pẹpẹyẹ across a genuine multi-session task to determine whether its supervision result adds enough value beyond direct owner plus `handoff`.
- Obtain independent `atunwo` review of the exact PR candidate and let `wo-pr` steward CI and review feedback.
