1. The structure I would build today

A small task interface over deep, selectively loaded expertise. This is a proposed product architecture, not a demand for a new directory tree, skill count or agent fleet. A user can name a specialist; Alárinà can choose and compose owners when needed. One agent can apply several methods.

Task interface

Intent and stopping point

Explain, decide, plan, build, review, publish or investigate a past event. The entry point identifies the result the user needs and the authority already granted. It does not prescribe a fixed procession through every skill.

Owned methods

Expertise and judgment

Domain interpretation, decision interviews, causal diagnosis, architecture, implementation, independent review and presentation retain their useful methods. References carry mechanisms, exceptions and counterexamples—not merely names of disciplines.

Project / host capabilities

Mechanics and enforcement

Native permissions and invocation controls, project tests, parsers, installation managers and package checks do the mechanical work they actually support. A hypothetical native replacement is not grounds to delete a working capability.

Human result and proof

Inspection and acceptance

Return the change, answer, decision or plan with evidence at the same candidate. A human-readable view makes that evidence inspectable; it neither invents acceptance nor replaces the underlying records.

Ownership rule: keep meaning and authority canonical; use structure or enforcement for mechanical obligations where it actually covers the boundary. Retire redundant procedure, not the explanation of the contract.

2. Follow the actual work

These are the workflows the rebuilt design must preserve or deliberately improve. Routes below explain existing responsibilities; they are not new mandatory pipelines.

Repair accepted behavior

Restored, not newly invented

Alága → existing owner and consumers → causal repair → affected-boundary proof

A retry defect must be checked against the actual external effect and persistent state, not just a local success flag. Keep the stateful, framework, compatibility and test-effectiveness references. Architect is conditional on a genuine structural question; a simple fix need not become an initiative.

Preserve: direct delivery, intent versus observed behavior, consumer tracing, nonzero executed checks and explicit limits. Method.

Make a consequential decision

Separate interface retained

Àròjinlẹ̀ → answerable decision frontier → confirmed understanding → caller

An interview can settle a product, technical or other consequential choice without authorizing implementation. Atọ́nà consumes confirmed choices when an initiative exists; it does not need to own every decision interview. Amọ̀ṣẹ́ resolves project meaning, not user preferences.

Why not fold now: decision closure and initiative progression are different completion contracts. A replacement must show standalone use, dependency ordering and no renewed approval loop. Method.

Carry and resume an initiative

Continuity retained

Atọ́nà → one current HTML plan → dependency-ready work → integrated acceptance

Keep the accepted direction, workspace/candidate, material alternatives, proof and next unresolved outcome in one living plan. On resumption reconcile actual state rather than reopening settled questions. A completed ticket or handoff is not the delivered outcome.

Preserve: progressive shaping, meaningful decomposition, premortem, recovery and stopping at the requested result. Method.

Explain, present and review a change

Distinct boundaries retained

Source owner → Ọ̀rọ̀ / Fihanmi → native PR brief or HTML Artifact → reader

Fihanmi selects a faithful view; HTML Artifact constructs and checks a browser document when needed. Its controls, dependency rules, source composition and accessible fallback remain useful capabilities. Seda PR owns the provider-facing brief and publication. Àtúnwò owns independent judgment, not approval or merging.

A short explanation can stay in chat. A PR body stays usable in native Markdown. A polished page does not prove comprehension. HTML method.

Explain wasted work

Mechanical capability recovered

Native records → bounded session inventory/parser → Àyẹ̀wò causal reconstruction → earned remedy

Finding and normalizing records is not the same job as interpreting them. The recovered adapter and regression protect a working acquisition capability. The postmortem separates a mention, a file read, a tool action and an observed effect; it does not turn counts into causes.

Replacement condition: an available native export must demonstrate equivalent required discovery, relationships and coverage before the adapter is removed. Recovered adapter.

Judge whether guidance helps

Readable view implemented

Question → frozen task/candidates → authorized native run → independent checks → current report

Keep the reusable tasks and calibrated oracles while changing the interaction that made results hard to inspect. The new report uses the existing summary validation; it refuses stale or incomplete evidence and preserves failed, unrun, replay and unknown states.

This pilot improves the available presentation, not a measured success rate or review time. Implementation.

4. The eval system: change the experience before deleting the safeguards

The earlier proposal bundled tasks, oracles, execution scaffolding and historical records into a single deletion decision. The replacement design separates them. Stable tasks support comparison; the execution interface can change; the evidence must remain interpretable.

        ↓

        ↓

Nothing in that path launches a model or regrades an artifact. The report writes only a disposable temporary summary. Exit 0 means a validated view was displayed, not that a model passed; exit 2 reports invalid or unavailable evidence.

  --study .qp/alaga-engineering/reuse-1 \

7. Premortem and recovery

Recovery becomes stagnation

Warning: everything is retained indefinitely because it once existed. Response: evaluate one real costly workflow and a specific replacement. A resource can still be retired when its obligation is obsolete, subsumed or intentionally no longer supported.

New view hides bad evidence

Warning: attractive output omits unrun cells, unknown costs or stale candidates. Response: use the original validation owner and tested rejection cases. Do not let report validity become an acceptance verdict.

Native controls break legitimate use

Warning: manual-only metadata is valid but the expected command fails on a supported host. Response: test the actual explicit invocation and an incidental mention separately. Preserve version and installed-source identity. No successful host trial is claimed here.

Another rewrite loses depth

Warning: a capability is replaced by its topic name or a shorter paragraph. Response: show the actual before/after task path, method, failure cases and accepting evidence. Change one meaningful boundary; do not merge unrelated cuts into one claimed improvement.
