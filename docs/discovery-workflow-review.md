## Additional QP judgment

Ideation previously risked rejecting unfamiliar mechanisms for lacking outcome evidence before testing them. Separate contradicted assumptions from unknown ones: retain a potentially valuable contender when a bounded discriminating test is feasible. This is a QP editorial judgment, not an upstream effectiveness result or a promise of breakthrough ideas.

## Trigger boundaries

| Example request | Intended starting point |
| --- | --- |
| “Big idea, but I don't know where to start.” | Atọ́nà exploration; identify purpose gaps and next useful evidence. |
| “None of these product directions solves the problem.” | Atọ́nà ideation; reframe assumptions and examine different mechanisms. |
| “I need to see how this behaves before choosing.” | Àdánwò; a truthful disposable interaction. |
| “Help me work out what I actually want.” | Àròjinlẹ̀; use prototypes when experience is needed to answer. |
| “Implement this accepted fix.” | Alága delivery; no new discovery loop. |
| “What does this provider API support?” | Direct lookup or Ìwádìí research as warranted. |
| “Split this accepted specification into tasks.” | Atọ́nà decomposition; no initiative plan required. |

These are source-review expectations, not observed native skill-discovery results. Package checks establish identity and local-link validity; they do not establish improved creativity, selection accuracy or user comprehension.
