# Fresh history at 0.1.0

By qp-skills 6.2.0 the history carried many renames, removed skills and superseded designs. We chose to delete the public `quantipixels/skills` repository and recreate it with one initial commit at version 0.1.0, rather than force-pushing over it or making it private. A public fork, `Omisamuel/skills`, keeps the old history up to August 2026 and becomes independent of this repository. The full old history (all branches and tags) and an export of its pull requests, releases and settings are kept in the private `quantipixels/skills-retired` repository, on branch `archive/github-export` for the export.

Consequences: pull request and release pages from before 0.1.0 are no longer on GitHub. Existing installs see the version go from 6.2.0 to 0.1.0 and should be reinstalled.
