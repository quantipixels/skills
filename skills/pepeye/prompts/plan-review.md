# Independent plan review

Use when the entrypoint's plan-review gate applies. Give a fresh reviewer the fixed plan and decisive evidence; keep the assignment read-only.

> Review **[exact plan]** against **[accepted outcome, constraints, and evidence locators]** before **[dependent execution]**.
>
> Find assumptions, missing decisions, dependency/ownership errors, infeasible steps, weak proof, and recovery gaps that could materially defeat the outcome. Consider a simpler route where it changes feasibility, cost, or risk.
>
> Return actionable findings with evidence and consequences, material uncertainties, and whether execution can proceed. Distinguish blockers from optional improvements. Do not rewrite the plan or advance execution.

Route confirmed findings to the responsible owner. Review again only when changes invalidate the prior judgment. This does not replace candidate code review through `atunwo`.
