# Test effectiveness

Use for reviews of test consolidation, assertion strength or generated tests. This adds proof methods to the main skill's read-only review.

For test consolidation, each obligation must be obsolete or covered at least as strongly by retained proof. A generator that omits an edge, an unchecked calculation or an integration test that never reaches the failure does not subsume its regression check. Complementary fast and realistic checks can remain. Authorized test changes belong to the builder. Judge TDD order from executed evidence; do not require TDD everywhere or a separate retention workflow.

For weak assertions, trace inputs through the exact matcher and name a realistic defective value/effect it accepts. Use distinguishable values for swapped/dropped fields. Check framework semantics; counts, variety and coverage percentages are not quality verdicts. For generated tests, assess valid inputs, vacuity and oracle independence. Consult `akole` for deeper property or numeric methods under this review's read-only limits. Do not alter source to create a score; return unexecuted proof gaps to the change's author.
