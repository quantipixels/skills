# Pattern corrections

These are diagnostic contrasts, not universal bans or a component catalogue. Apply only the row that explains the target's failure.

| Observed habit | Correct the underlying decision | When the familiar form earns its place |
| --- | --- | --- |
| Centered slogan, badges and equal feature cards regardless of subject | Put the actual work, useful comparison, or consequential decision first; compose the remaining material around it. | A campaign with one clear action may need a centered hero. Equal cards suit genuinely comparable options. |
| Every section is a rounded panel with an icon, label and paragraph | Use grouping and alignment for related content; reserve containment for independent objects or actions. Vary emphasis by importance, not arbitrary alternation. | Repeated records, selectable products and independent modules benefit from stable containers. |
| Beige editorial styling or dark neon replaces the previous default everywhere | Derive the visual language from the subject, existing identity and usage setting. A new palette without a new information hierarchy leaves the failure intact. | Either aesthetic is valid when the brief or actual environment supports it. |
| Tiny uppercase labels, section numbers, status pills and technical ornament add apparent sophistication | Retain only labels that orient, distinguish or communicate real state. Give headings and primary material enough hierarchy to work without decoration. | Sequence numbers, version labels and status indicators can convey essential meaning. |
| Oversized headings, tight tracking and huge gaps displace the useful content | Fit real copy to the composition and device; use scale contrast without forcing a line-count rule or shrinking important text. | Expressive display type and generous space can be the subject's strongest move. |
| A dashboard or diagram stands in for an explanation | Show the actual comparison, mechanism, example or consequence. Use a table for exact lookup and a diagram for relationships. | Genuine quantitative patterns, live operational state and meaningful topology warrant those representations. |
| Motion or visual variety is added to prove the page was designed | Use movement for state, continuity or an intentional experiential effect; make the static and reduced-motion reading complete. | A kinetic portfolio can earn substantial motion; an operational page may earn none. |

A useful transfer changes the reader's experience: an implementation plan can expose the actual API exchange beside the state change; a product page can make the material and use visible; a dense comparison can align the values the reader must judge. These are possible design moves, not required layouts.
