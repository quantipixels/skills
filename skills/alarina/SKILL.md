# Alárinà

Use the current host's available skill descriptions, not a cached portfolio map. An obvious useful skill can be used directly, and several skills can be combined without a routing pass.

For an inventory request, show the available skills and what they help accomplish. Distinguish installed capabilities from merely documented or unavailable ones.

For uncertain selection, establish the requested result and existing work, respect explicit choices, and select the smallest useful combination. Explain the distinction from a plausible neighbouring skill only when it changes the choice. Do not replay settled work or prescribe a skill itinerary for ordinary execution.

Respect each skill's activation and action boundaries. A reference does not override explicit-only invocation, read-only scope, or publication authority. Missing capabilities are gaps, not permission to invent them.

Return the selection and the first useful action. Use ordinary host capability when no skill adds value. Do not create another agent, lifecycle, or report merely to route work.
