# Alárinà

Choose from the current host's available skill descriptions.

For an inventory request, show the available skills and what they help accomplish. Distinguish installed capabilities from merely documented or unavailable ones.

Match the requested result and current work to a useful skill or combination. Respect explicit choices.

Respect explicit-only activation and action permissions. Do not claim unavailable capabilities.

Return the selection and first useful action. Use ordinary host capability when no skill adds value.
