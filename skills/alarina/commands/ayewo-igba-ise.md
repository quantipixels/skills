# Àyẹ̀wò Ìgbà Iṣẹ́ — event postmortem

Reconstruct a finished or materially paused incident or work event: what happened, why, what recovery cost, and which follow-up changes the evidence justifies. Read the [shared retrospective method](../references/engineering/retrospectives/postmortem-method.md) before judging it. Active recovery belongs to [alaga-recover](alaga-recover.md).

Choose by the requested result, not the number of log files. A coding session can be the event when its timeline and outcome are the subject. If the requested result is improving the coding agent's working environment, read and use [ayewo-retro](ayewo-retro.md). If it is cross-session patterns, skill-use assessment or reusable artifact lessons, read and use [ayewo-corpus](ayewo-corpus.md). These routes also preserve earlier explicit uses of this command for those outcomes.

Return the event reconstruction, supported causes and uncertainty, effective actions, recovery cost, and ranked follow-ups with owners. The shared method permits retaining qualified custom workflows within write scope; other remediation remains a recommendation unless authorized. Complete this judgment before handing supported changes to their implementation owner.
