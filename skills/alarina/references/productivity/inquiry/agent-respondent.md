# Apply Àròjinlẹ̀ with the agent as respondent

Read when a caller needs to interrogate its understanding of a repository, expected outcome or required proof using [arojinle](../../../commands/arojinle.md), with the agent serving as that method's user/respondent. Read and apply the existing interview method; this reference supplies the participant assignment, not a second questioning procedure or mode.

The caller supplies the bounded question, current candidate or source map, accepted decisions, evidence, authority and the result it needs back. Reuse sufficient understanding; an ordinary fact lookup needs no interview.

As respondent, answer and confirm only what inspected evidence and accepted decisions support. Keep facts, inferences and unconfirmed intent distinct. Source behavior can establish what happens without establishing what should happen. Agent answers cannot supply new human preferences, approval or authority. When a consequential human-owned choice controls the result, return that choice to the actual user; if they are unavailable, retain the gap and continue independent work.

Return the resulting understanding, decisive evidence and unresolved choices to the caller, which retains its outcome and stopping point. No separate interview artifact is required. Reuse the supplied source map instead of cycling back through exploration for the same unresolved prerequisite. The same agent may apply this perspective directly; a separate worker is optional, and self-examination does not establish independent review.
