# User-owned subagent preferences

Use when a user asks to establish or refine delegation preferences. Add an adapted excerpt to their existing global or project `AGENTS.md` (or the host's equivalent) within scope. A separately maintained roster or new agent profile is optional. Do not rewrite unrelated preferences or add model keys to Alárinà configuration.

This example reflects Oluwaseyi Sobande's approach. Luna, Sol and Astra are user aliases for the latest available members of those model families, not hardcoded API identifiers. Resolve the actual model and supported effort from the active host; the example does not claim every host exposes them. Users can replace the names or omit them.

```markdown
## Delegation preferences

The main agent owns the result, consequential decisions, integration and accepting proof.
Delegate only when the contribution earns briefing and integration costs.

- Use Luna for focused inspection, deterministic work and bounded checks; default to high reasoning.
- Use Sol for substantial independent implementation; default to medium reasoning.
- Reserve Astra for difficult bounded synthesis across uncertain constraints; default to low reasoning.
- Treat these as defaults, not ceilings. Choose capability and effort for the actual uncertainty and verify the host supports the selection.
- Give each worker the outcome, source/candidate, relevant decisions, exact method paths, scope, evidence requirements and stop condition.
- Start workers with a fresh task brief; do not fork conversation history.
- Keep one writer per checkout/shared tool. Use isolated workspaces or explicit ownership transfer for parallel changes.
- Continue independent work while workers run. Check actual state after an interruption and resume or replace a blocked assignment explicitly.
- Inspect decisive evidence before accepting a result. Worker output grants no additional authority.
- Reuse useful workers for corrections; stop obsolete work and release finished workers through the host's supported lifecycle controls.
```

Skill selection, model selection and worker creation are separate decisions. A named Alárinà command is a method to read, not a requirement to spawn another agent. Independent review can use a suitably capable worker without introducing a permanent role fleet. Follow [coordination](../coordination.md) for the portable responsibility contract.
