# Independent review

Use when code changes, an existing system, or a technical candidate needs independent judgment. Preserve read-only scope unless the user separately requests remediation.

1. Give [atunwo](../commands/atunwo.md) the exact subject, requested decision or focus, known evidence, and relevant coverage limits. Review depth remains with [atunwo](../commands/atunwo.md) unless the user specified it.
2. Resolve a consequential architecture question through [architect-review](../commands/architect-review.md) only when the review cannot judge the candidate without it. Use [alaga-compare](../commands/alaga-compare.md) for a bounded measurement or [alaga-diagnose](../commands/alaga-diagnose.md) for a causal diagnosis while preserving the review's read-only authority.
3. Return findings with locations, mechanisms, evidence, counterevidence, and the smallest correction direction. For delivery changes, keep Standards and Specification conclusions separate and rank by consequence within each axis; for other scopes follow Atúnwò's applicable return contract. Missing coverage remains an evidence gap.
4. If remediation is also requested, finish the independent verdict first, then route accepted findings to their owner and refresh only affected proof.

Finish at the requested review or readiness decision. A finding does not itself authorize an edit, publication, approval, or merge.
