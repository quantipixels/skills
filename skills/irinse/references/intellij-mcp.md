# IntelliJ MCP

Official source: [JetBrains IntelliJ IDEA MCP Server](https://www.jetbrains.com/help/idea/mcp-server.html)

Use IntelliJ MCP for IDE-backed code insight, navigation, run configurations, terminal actions, and debugging when the installed IDE and coding-agent client support it.

Verify the current IDE version, required plugin or built-in server, project trust, server state, client configuration, exposed tools, and project-root scope from official documentation. Installation does not authorize enabling the server or modifying a client configuration. Ask separately for each mutation.

Constrain the exposed project and tools. Treat indexes and inspections as evidence that can be stale or incomplete. Record IDE and plugin versions, project identity, requested operation, index state, errors, and corroboration.
