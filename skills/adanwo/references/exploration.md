
# Exploratory experiment

Build the smallest disposable decision instrument for one question that discussion or a cheaper sketch cannot settle. Pin the audience, tested dimension, sufficient fidelity, variants if useful, exclusions, disposal boundary, environment, and permitted effects. Several variants may share one boundary only when they answer that same question.

Represent the tested dimension truthfully: behavior must be exercisable, visual judgment needs sufficient visual fidelity, and CLI/API ergonomics needs a runnable interaction. Label other simulations. A simulation cannot prove the dimension it replaces.

Use existing components, fixtures and preview capability when they improve fidelity. Keep work temporary by default or under `.qp/adanwo/exploration/` when persistence is needed. Do not alter the accepted candidate or create real customer, credential, payment, message, or irreversible effects without separate authority.

When a state-model experience needs structure, offer guided scenarios, a reset path and free exploration; they are optional rather than a universal prototype format. Subjective claims require an attending human. Record what the person observed, not the author's prediction.

Revise while the artifact still answers the same question. Finish with one result:

- `DECIDED` — direct experience selected or confirmed an answer;
- `INCONCLUSIVE` — the artifact was exercised but did not distinguish the alternatives;
- `BLOCKED` — a named environment, capability, authority, evidence, or human-attendance gap prevented the test; or
- `ABANDONED` — the user ended the experiment without a decision.

Return the question, artifact locator, fidelity and simulations, observations, result, unresolved alternatives and limits. A prototype proves only dimensions it represented truthfully; runnable does not mean production-ready.

Carry forward the decision, selected contract/assets and evidence, not the disposable implementation. Retaining or delivering prototype code is a separate result requiring its own authority and proof.
