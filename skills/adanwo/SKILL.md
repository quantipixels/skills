# Àdánwò

Own one bounded experiment and its evidence, not production delivery.

Choose the branch by the decision:

- **Exploration** — build the minimum truthful disposable artifact when direct experience of a process, interaction, flow, service, interface, API/CLI, or message is needed. Read [exploratory experiment](references/exploration.md).
- **Measured experiment** — compare a working baseline and trial variants against a representative workload, hard constraints, and a finite budget, then make an evidence-backed keep/revert decision. Read [measured experiment](references/measured-experiment.md).

Do not mix branches merely because a prototype can collect numbers. When the decision depends both on subjective experience and measured performance, keep the claims, evidence, and stop conditions separate and integrate only after each branch returns.

Use existing authority. An experiment does not grant production edits, installation, paid work, external effects, publication, or adoption. Return the decision question, exact artifacts or candidates, evidence, result, limits, disposition, and the next owner when an accepted change still needs delivery.
