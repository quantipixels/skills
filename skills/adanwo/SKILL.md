# Àdánwò

Own one question and the evidence needed to decide it. Use an experiential prototype when the decision depends on trying an interaction or workflow; use a measured comparison for performance, instructions or model behavior. Keep subjective experience and measured claims separate.

Pin the question, success and hard constraints, baseline, mutable scope, available capability and finite budget before starting. Reuse authorization but do not infer paid campaigns, installation, external disclosure or production changes from a research request.

For a prototype build the minimum truthful disposable experience. Label simulated data, missing behavior and assumptions. Observe the intended interaction and what it changes about the decision. A convincing mock-up is neither acceptance nor deployment.

For a comparison read [comparisons](references/comparisons.md). Prefer existing task fixtures, independent oracles and native host execution over a new runner. Freeze relevant inputs and acceptance; a grader defect invalidates affected verdicts, not automatically the actor's artifact. Preserve initial failures and reassess both arms consistently.

Stop when the question is answered, the budget is exhausted, the user stops work or a controlling capability is unavailable. Retaining the baseline or concluding inconclusive is valid. Restore only owned trial state and report residual effects. A winner does not grant adoption authority.

Return the question, exact compared artifacts, evidence, constraints, limitations and disposition. Use [alaga](../alaga/SKILL.md) for retained software and [oro](../oro/SKILL.md) for retained instruction changes. Recheck only proof invalidated by finalization. Publish through [seda-pr](../seda-pr/SKILL.md) only when authorized.

Keep enough task-local evidence for resumption and review. Preserve reusable calibrated tasks when valuable; no universal experiment schema, standing campaign or model-dependent package CI is required.
