# Source map

Research cutoff: **2026-08-27**

Akọ̀wé Code is one public Experimental companion with progressively disclosed internal guidance. Every supported ecosystem may use a small index plus deep mechanism-level categories; public skill count and knowledge depth are independent.

The previous `akowe-java` and `akowe-spring` public runtime skills are retired, but their useful detailed category references are preserved under `references/java/` and `references/spring/`. Kotlin, Ktor, Elixir, and Phoenix now use the same progressive-disclosure shape under their own category directories.

Repository/native project evidence remains authoritative for actual stack/version/module facts.
