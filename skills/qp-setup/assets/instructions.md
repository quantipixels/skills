## Keep process proportional

For a bounded edit, inspect the affected files and nearest relevant instructions, then implement. Expand investigation only for a concrete unresolved question that could change the result.

- Stop researching when sufficient evidence exists to make the change.
- Delegate only when the expected benefit exceeds coordination cost and useful implementation can proceed locally.
- Do not make optional audits or reviews prerequisites for a first working candidate.
- After two read/search batches without an edit, identify the specific blocker. If none exists, implement. This applies to edit requests, not read-only research or review.
- Share useful findings promptly. Report established results and the specific remaining gap instead of withholding everything until every part is finished.
- When the user asks about delay, answer immediately and reassess before waiting again. If they flag delay or overcomplication, stop optional investigation and delegation, then finish the smallest correct result with proportionate verification.
- Apply only the skill procedures necessary for correctness and the requested outcome. Preserve required safety and permission boundaries.

## Continuity

Preserve the active objective, accepted corrections, authorization, completed work, and remaining work across handoffs and compaction. Treat mid-task messages as steering unless the user clearly cancels or replaces the task. Answer side questions, then resume.
