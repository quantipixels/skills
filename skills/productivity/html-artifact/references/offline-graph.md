# Offline relationship graphs

Use this path only when an interactive relationship graph improves inspection of supplied meaning. Ordinary prose, tables, static diagrams, or an existing host renderer remain preferable when they serve the reader better. This is a focused renderer integration, not the default form for every report.

## Contract and boundary

The local builder delegates graph layout/drawing to Cytoscape and dependency assembly to esbuild. It emits a single HTML candidate with embedded runtime and static data; no CDN, service, telemetry, cookies, or runtime data request is introduced. Source links are reader-activated evidence references, not fetch instructions.

The caller still owns source selection, labels, the directed/undirected interpretation, coverage, and semantic correctness. Positions convey layout only, not a new conclusion. All nodes, identifiers, relationships, and source links remain in a visible text view if JavaScript or the renderer fails. The builder does not determine importance, causality, scores, categories, or review readiness.

Use the [builder](../scripts/graph/render.mjs) after selecting this representation:

```bash
cd <skill-root>/scripts/graph
npm ci --ignore-scripts
node render.mjs --input /path/to/relationships.json > /temporary/candidate.html
npm test
```

Node 22 is the baseline. The committed `package.json` and lock pin Cytoscape 3.34.2 and esbuild 0.28.2. Installation uses the network; the delivered artifact does not need it. Do not put the provisional redirected output directly over a canonical shared artifact: the caller validates the result before native publication, or uses `akosile` for shared CAS publication when that workspace is selected.

The input is a data-only subset of native Cytoscape elements:

```json
{
  "title": "Service relationships",
  "summary": "The accepted design's write path.",
  "directed": true,
  "source": {"label": "Accepted design, revision 4", "href": "https://example.test/design"},
  "elements": [
    {"data": {"id": "api", "label": "API"}},
    {"data": {"id": "db", "label": "Database"}},
    {"data": {"id": "write", "label": "writes", "source": "api", "target": "db"}}
  ]
}
```

Node and edge `data.href` links are optional. IDs and labels must be non-empty; IDs are unique; edges reference existing nodes. `directed` must be explicit. Unknown/style/executable fields are rejected rather than interpreted or silently discarded. The current focused view accepts up to 2,000 elements and the CLI rejects input larger than 2 MiB; split the view or choose another capability when that ceiling is unsuitable. Do not truncate source meaning to fit it.

Control/fallback labels are English in this implementation. Choose another path or explicitly localize the maintained control implementation when the reader requires another language; user-supplied labels alone do not localize the controls.

## Compose into an owner document

The optional `--shell /path/to/owner.html` replaces exactly one `<!-- QP_GRAPH -->` marker with the graph component. That shell is trusted, owner-authored implementation code—not an untrusted transcript or raw source document to execute. Its existing script, style, trust and delivery obligations remain caller-owned. The builder does not sanitize the shell or claim the complete shell is offline.

Without a shell, the builder embeds QP's visual foundation and theme control and a restrictive standalone CSP. With a shell, the containing document owns equivalent controls and CSP. The graph's structured source labels remain data in both modes.

## Proof and provenance

`npm test` exercises malformed identities, endpoint checks, source-link safety, escaping, deterministic output, shell composition and CLI failure behavior. `.github/browser/test_graph.py` tests generated bytes through actual file navigation in Chromium, selection/keyboard controls, narrow width, no network requests, JavaScript-disabled fallback and forced renderer failure. The output records normalized source and embedded-runtime hashes plus dependency versions and the redistributed Cytoscape licence.

- [Cytoscape.js](https://js.cytoscape.org/) owns native elements, graph layout, and rendering. MIT-licensed runtime is bundled; its licence is retained in the output.
- [esbuild](https://esbuild.github.io/api/) owns local browser bundling. It is build-time only and not a reader dependency.

Source interfaces inspected 2026-09-05. QP integration code is original; no reference repository renderer is copied. Re-run package, Node and browser proof when dependency pins, input boundaries, rendering behavior, or delivery shape change. Automated browser checks do not certify all accessibility or semantic fidelity.
