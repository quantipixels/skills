# Logo usage rules

Use this reference to document or review rules for an actual approved logo system. Do not invent lockups, filenames, dimensions, clear space, colors, or platform variants.

## Establish approved behavior

Inspect source artwork, existing guidance, production use, export files, and approval records. Document only evidenced rules:

- approved lockups and the contexts each serves;
- color or monochrome variants and compatible backgrounds;
- clear space expressed from a named feature in the artwork;
- minimum size established by legibility proof for the target medium;
- permitted cropping, animation, co-branding, and responsive behavior; and
- prohibited transformations and approved exceptions.

When evidence is missing, mark the rule unsettled and request a decision or test. Do not turn common logo advice into brand policy.

## Review a use

Compare the exact asset and composition with the approved source. Check aspect ratio, geometry, color, contrast, clear space, minimum-size legibility, background interference, cropping, and partner-mark treatment where applicable. Report the exact mismatch and its evidence. Do not call a treatment approved because it looks conventional.

Keep source and export locations aligned with the project's existing asset convention. Use an approval workflow only when the project or user defines one.
