# Banner surface constraints

Load when a banner/cover/header/hero/ad/print surface needs more than the main skill's basic composition rules. Platform dimensions and ad specifications change; verify the current target's requirement or use the user-supplied specification before production export.

## Surface evidence

Pin:

- exact canvas/aspect ratio and any responsive/crop variants;
- platform chrome/safe area or print bleed/trim where applicable;
- viewing distance/device and minimum readable text/mark size;
- editable/source vs flattened export requirements; and
- current platform/file constraints that materially affect delivery.

Do not preserve a QP table of current Facebook/X/LinkedIn/YouTube/ad sizes as production truth. Use current owning documentation at execution time.

## Composition

- Keep one primary message/focal point and one primary CTA when an action is required.
- Keep critical copy/logo/action inside the proven safe region; do not rely on a generic “central 80%” when the target provides an exact crop/safe area.
- Treat logo/brand placement from the active Brand contract, not a universal top-left rule.
- Use image, type, illustration, geometry, or data as the dominant visual only when it supports the message and brand direction.
- Preserve editable text/CTA where the delivery workflow needs reuse/localization.

## Digital banners

Verify actual-size/mobile legibility, crop behavior, contrast, loading/asset weight where relevant, and interaction semantics for clickable/animated surfaces. Respect reduced motion when animation is present.

## Print / large-format

Use the printer/production specification for trim, bleed, color mode/profile, resolution, safe zones, and file format. Judge type/line/detail size from viewing distance and physical output rather than applying a fixed pixel rule.

## Art direction

Do not select from a fixed QP style catalogue. Derive visual direction from the current brand, message, audience, environment, and approved visual evidence. When external references materially improve direction, use current visual research rather than cached trend names.
