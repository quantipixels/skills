# Decision awareness

Use this protocol when decisions, dependencies, gaps, or consequence branches materially shape the exploration. It supports navigation, not complete decision closure.

## Map the relevant tree

Keep only the part of the tree needed for the current focus and lens. Record:

- premise, intended outcome, and controlling constraints;
- observed facts, assumptions, contradictions, and material evidence gaps;
- decisions or user questions that can change the inquiry;
- prerequisite, unblocks, and consequence relationships; and
- each branch as `OPEN`, `BLOCKED`, `SETTLED`, `DEFERRED`, or `STALE`, with its evidence or blocker.

Facts can settle an evidence branch. Only an authorized user answer or exact-current owning result can settle a material choice. Do not treat silence, an assumption, or a likely preference as a decision.

## Maintain the relevant frontier

The relevant frontier is the smallest set of actionable items whose prerequisites are settled and whose answers can materially improve the exploration. Classify each item as evidence the agent can investigate, user input only the user can supply, an owning specialist result, or a material decision visible but not owned by Ṣàlàyé.

Work evidence items without asking the user. Ask and wait for the smallest user-input item only when it blocks sound progress. Surface decision consequences without asking the complete frontier merely to force closure. Continue through an independent item when another is blocked.

Recompute the relevant frontier when evidence, user steering, a specialist result, or the current focus changes. Mark affected branches stale before reusing them.

## Transfer closure

When the user wants complete decision closure, hand Arojinle the current focus, relevant tree and frontier, settled facts and evidence, open decisions, gaps, dependencies, deferrals, authority, and known consequences. This is orientation, not proof that the decision tree is complete. Arojinle rebuilds and exhausts the material frontier and obtains final confirmation.

Include the relevant tree, current frontier, explored and blocked branches, gaps, and next useful action in the Ṣàlàyé result. Never call it a confirmed decision tree.
