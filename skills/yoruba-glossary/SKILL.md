# Yorùbá language and glossary

Own Yorùbá language guidance and learning, including technical-term decisions. Default to Standard Yorùbá unless the user specifies a variety; distinguish dialect, register and attested usage from error. Preserve exact identifiers and the user's chosen personal-name spelling.

Choose the requested mode directly:

- **Language** — explain or correct spelling, pronunciation notation, grammar or wording. Read [orthography and tone](references/orthography.md), [sentence composition](references/sentences.md), or [word formation](references/word-formation.md) as needed. Give the useful answer or corrected text and explain consequential changes.
- **Teach** — use the learner's goal, language and relevant language reference. Distinguish literacy from speaking ability, spelling/tone from pronunciation, and Standard Yorùbá from legitimate dialect/register. Use verified audio for listening/pronunciation claims and never assess spoken tone from text alone. Label proposed coinages and use contextual sources such as [Yorùbá Yé Mi](https://coerll.utexas.edu/yemi/index.php) or [Science in Yorùbá](https://scienceinyoruba.org/tao/) without treating emerging terms as settled. A lesson creates neither a course artifact nor a glossary record unless requested.
- **Terminology** — choose or propose a technical term using [word formation](references/word-formation.md). Use [glossary maintenance](references/glossary.md) for term status and authorized durable writes.

Use fully marked teaching examples. Resolve uncertain tones, senses and forms from context and reliable sources; unmarked input may have several readings. Offer alternatives or ask for the intended meaning instead of confidently inventing marks. Distinguish a sourced rule, a usage preference and a proposed coinage. User acceptance can establish a project term, not language-wide standard status.

Use bounded independent source checks when they materially help; require source locators, marked forms and uncertainty. Use `iwadi` for substantial research, `amose` for project-domain meaning, and `oro` for audience-facing prose.

Return the explanation, correction, lesson or term decision requested, with material uncertainty. Write a glossary only to an identified, authorized target; preserve exact identifiers and existing mappings. Teaching, discussion and term acceptance alone do not authorize durable writes.
