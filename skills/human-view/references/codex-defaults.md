# Codex defaults

Use before the first layout or a material recomposition in Codex. These are observed/reported design habits to inspect, not universal model defects. The brief, accepted design and specialist direction take precedence. Apply only corrections the actual content needs; do not repeat the general Human View method.

| First-draft reflex | Corrective move | Keep it when |
| --- | --- | --- |
| Centered slogan, equal cards and a footer before reading the material | Sketch the reading order around the actual specimen, decision or comparison before choosing containers. | One clear campaign action earns a centered hero; genuine peers earn equal treatment. |
| Huge tightly tracked heading with the useful content pushed down | Fit real copy and useful first-view content together; change scale, measure or placement. | Display typography is part of an explicit direction and remains readable. |
| Rounded panels, badges and uppercase labels applied to every section | Remove scaffolding that adds no grouping, orientation or state; strengthen the material's own hierarchy. | Containers and labels make independent objects, actions or states easier to scan. |
| Technical grids, dots, faux code and pseudo-diagrams as atmosphere | Show a real relationship or specimen; omit ornament that merely suggests expertise. | The grid, code or mark belongs to the actual data, canvas, measurement or explanation. |
| A familiar beige/serif or dark/neon theme presented as a new idea | Change the structural decision when it is generic; preserve colors and fonts the user actually asked for. | The chosen aesthetic fits the brief; familiarity alone is not a defect. |
| Hover effects, reveal animations or stock imagery added to make a page feel finished | Spend effort on real content, appropriate imagery and meaningful feedback first. | The asset or motion contributes to the intended experience without obstructing use. |

Do not simulate randomisation or manufacture a sacrificial first build. Choose deliberately before coding. Do not replace these habits with mandatory AIDA, GSAP, font bans, layout quotas or novelty for its own sake. Compare the delivered composition with the supplied design reference or accepted visual direction using the owner's existing render evidence; correct specific departures in hierarchy, density and visual conventions. A checklist cannot establish visual quality.

Model and host guidance vary; do not assume a historical Codex prompt governs the current session. Revisit these checks against actual outputs when the model or harness changes.
