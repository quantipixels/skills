# Documentation maintenance

Use when project documentation needs useful initial coverage, improvement, drift assessment or reconciliation against current implementation and accepted decisions. During coding delivery, [alaga-deliver](../commands/alaga-deliver.md) owns the affected-documentation check and closes its delivery evidence, invoking this playbook or Akọ̀wé only for a separate set-level need. A focused architecture, domain, or wording-only request can stay with its specialist.

1. Give [akowe-audit](../commands/akowe-audit.md) or [akowe-sync](../commands/akowe-sync.md) the document set, final implementation boundary, accepted decisions, audience, and requested stopping point. For broad project documentation work, apply the [project baseline](../references/engineering/documentation/project-baseline.md) to useful missing coverage as well as existing files. Otherwise inspect the affected overview, README, standards, procedures or domain records within the named scope. Include established legacy knowledge when relevant; generated outputs and historical records retain their actual sources of truth.
2. Route structural claims and architecture-overview updates to [architect-document](../commands/architect-document.md), unresolved structural facts to [architect-survey](../commands/architect-survey.md), domain meaning and durable-record eligibility to [amose](../commands/amose.md), and human-facing wording to [oro-eniyan](../commands/oro-eniyan.md) or agent-facing guidance to [oro-sigidi](../commands/oro-sigidi.md). Use [iwadi](../commands/iwadi.md) only when substantive external evidence controls the correction. Return each result to the same documentation set.
3. For `audit`, stop at supported findings and coverage. For authorized `sync`, apply the corrections and verify links, examples, commands, generated sources, and affected reader journeys as applicable.
4. Use [fihanmi](../commands/fihanmi.md) or [html-artifact](../commands/html-artifact.md) only when presentation materially improves the requested human result; they do not decide what is true.

Finish with the maintained document state, verification, unresolved evidence gaps, and any separately owned publication step. A corrected source file does not prove a generated or published copy changed.
