# Feature delivery

Use when an idea or changed behavior needs decisions, structure, implementation, or integrated proof. A settled bounded coding outcome can enter [alaga-deliver](../commands/alaga-deliver.md) directly without creating an initiative.

1. Recover the current state, accepted decisions, requested stopping point, candidate, and proof. Use [atona-direction](../commands/atona-direction.md) for unsettled direction, [seda-spec](../commands/seda-spec.md) for behavior, [seda-tickets](../commands/seda-tickets.md) for decomposition, or [atona](../commands/atona.md) for initiative sequencing and combined acceptance.
2. Let the unresolved result choose the next owner. Use [arojinle](../commands/arojinle.md) for consequential human choices, [adanwo](../commands/adanwo.md) for questions that need direct experience, [iwadi](../commands/iwadi.md) for substantive external evidence, [amose](../commands/amose.md) for domain meaning, and [architect-design](../commands/architect-design.md) for consequential technical structure. Reuse sufficient settled results.
3. When the outcome is accepted and bounded, give [alaga-deliver](../commands/alaga-deliver.md) the behavior, scope, constraints, candidate, and accepting evidence. It owns implementation, verification, and reconciliation of documentation affected by the final change. Use the [documentation maintenance playbook](docs-maintenance.md) when a whole document set needs separate audit or synchronization.
4. Return material findings to the same initiative plan. Use [atunwo](../commands/atunwo.md) for requested or warranted independent judgment and reroute valid findings to their owner. Continue only through the authorized outcome.
5. Use [seda-pr-description](../commands/seda-pr-description.md), [seda-pr](../commands/seda-pr.md), or [wo-pr](../commands/wo-pr.md) for the requested description, publication, or stewardship result. Merge, deployment, and release retain their own authority.

Finish at the requested direction, contract, plan, decomposition, verified implementation, or publication stop. A plan or owner handoff is intermediate when the user requested completed delivery.
