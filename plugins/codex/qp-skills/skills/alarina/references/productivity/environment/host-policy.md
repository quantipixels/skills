# Native host policy

Read when coordination depends on model selection, reasoning effort, or host-native worker behavior. User and host rules govern execution; portable coordination is not a provider configuration tutorial.

User and host settings own model and effort choices. Choose the lowest supported effort adequate for ambiguity, consequence, interacting constraints, inference difficulty, and verification cost. Raise effort when those factors earn it; no failed low-effort trial is required.

Check prerequisites only for the selected worker and required capabilities; do not preflight an unused roster. Reuse current evidence until the relevant configuration, host or assignment requirement changes. Use the host or project interface when discovery or enforcement needs investigation. Block only work depending on an unmet requirement; report unavailable runtime evidence rather than treating requested settings as observed behavior.

A default model or effort is not a ceiling. Keep settings user/host-owned and verify effective behavior through the host when enforcement matters. Use current host help or official documentation only for the configuration detail needed by the task. Preserve authority, one-writer and evidence safeguards regardless of host or profile availability.
