# Àyẹ̀wò — coding-session retro

Improve the coding agent's working environment from an actual session. Use the supplied session, or the current session when none is named. Read the [shared retrospective method](../references/engineering/retrospectives/postmortem-method.md) and [session analysis](../references/engineering/retrospectives/agent-session.md).

Trace observed friction to navigation, available information, tool economy, enforcement, review standards or instruction placement. Inspect the actual source/check wiring before recommending more instructions. Distinguish a missing rule from a clear rule that was not followed; rank concrete improvements rather than inventing a lesson for every mistake.

Use known transcript locators directly. Read [local session evidence](../references/engineering/retrospectives/local-session-evidence.md) only when persisted history needs inventory or relationship normalization. Multiple rollout files do not by themselves require corpus analysis. Use [ayewo-corpus](ayewo-corpus.md) when the recommendation depends on recurrence, prevalence or skill-use claims across independent sessions; consume its result without repeating the reconstruction.

Return the observed friction, decisive evidence, smallest change, owner, expected benefit and falsification check. Keep environment recommendations separate from incident reconstruction and measured model improvement. The shared method permits retaining qualified custom workflows; explicit read-only requests still control. Other remediation remains a recommendation unless authorized; then route instructions to [oro-sigidi](oro-sigidi.md), mechanics to [alaga-deliver](alaga-deliver.md), or another actual owner. This command grants no installation, access expansion, telemetry or publication authority.
