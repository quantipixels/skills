# Focused behavioral evaluations

Alárinà's package and compiler checks prove that files, routes and provider artifacts are valid. The [Alárinà cases](alarina/README.md) ask whether a model selects the entrypoint, respects the requested stopping point and completes a bounded task. They run only when a change could alter those behaviors. Case presence and JSON validity are not evidence of model success.

For a model comparison, freeze the candidate, task, acceptance and run budget. Use fresh sessions with compatible model, effort, tools and permissions. Give the actor only its case and necessary setup; keep expectations private. Record actual loading, actions, output, interventions and limits. Compare with direct-owner work only when claiming an advantage over it. A supplied skill bypasses native discovery, and a routing answer is not an executed outcome.

Historical observations and the published-tag migration evidence remain under [Alárinà](alarina/README.md). Retired prompts, engineering fixtures and checker code remain available in Git history. Do not count earlier runs against revised cases as fresh evidence.
