These are reusable inputs for specific unresolved decisions, not a certification suite for each skill. Select a case only when source review, a script smoke check or existing project proof cannot answer the question. Do not run every row after an instruction edit. Most cases are unrun protocols; their presence is not performance evidence.

## Run only the selected boundary

State what outcome would change the decision and set a finite authorized budget. For comparisons, hold the task, candidate inventory, model/effort and material host conditions constant. Freeze the exact source and applicable references, keep expected outcomes outside actor inputs, and use fresh disposable workspaces/sessions where needed. Record real isolation rather than claiming a directory is a sandbox.

A supplied-instruction probe and a native-discovery trial are different conditions. A route proposal does not establish actual actions, runtime guarantees or improvement. Preserve commands, artifacts, wrong-source attempts, missing evidence and intervention cost. Do not silently retry until a case passes. Native workers are optional; one agent can apply several methods.

C01 can use `evals/engineering/fixtures/verification/`; C02 uses `profile/`; C03 uses `batching/`; C04 and C06 use separate copies of `migration/`. Reuse a current project when it supplies better evidence. Publication, merge, real installs and destructive operations remain outside these cases' authority.
