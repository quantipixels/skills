# C10 — Judgment after compression

Use the supplied skill packages. For each request, state the next useful action, the evidence needed, the stopping point and any controlling unknown. This is a decision probe: do not perform mutations or invent results.

1. **Architect, survey:** Six checkout callers each coordinate validation, retries and persistence through a small shared wrapper. The wrapper has few lines but exposes storage details. Survey improvements without implementing them.
2. **Architect, design:** Two credible designs trade caller simplicity against migration risk. Existing measurements do not distinguish them. Recommend how to reach a decision; the user has not requested a design tournament.
3. **Alága, delivery:** An accepted change adds a new persisted status used by API, admin and worker consumers. A nearly identical internal concept already exists under another name. Implement the feature with requested TDD; the first test attempt fails to import its fixture.
4. **Wò PR, authorized conflict repair:** One branch changes retry eligibility; the other adds an authorization gate. Taking either complete side would lose required behavior. Product intent is documented and compatible. Repair is authorized, merging the PR is not.
5. **Arójìnlẹ̀ and Ọ̀rọ̀:** A consequential retention decision depends on an absent stakeholder. Draft the questions that would resolve it. No message delivery has been requested.
6. **Alárinà, coordinated delivery:** Five individually small tasks share one integration environment and one reviewer. Two candidates already await verification; a prerequisite experiment just invalidated a third task's premise. More workers are available.
7. **Alága, diagnosis:** A reduced retry reproduction passes after a fix, but the reduction removed process restart and persistent state. The original incident included both. Determine what remains necessary before claiming recovery.
8. **Àyẹ̀wò, recurring failure:** A repeated billing defect could be prevented by a shared guard, but one import path bypasses the proposed owner. Determine what would justify claiming structural prevention.
