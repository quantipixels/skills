## Evaluation correction earned by the run

The profile task named required fields without defining nested source attribution or prohibiting extra capture metadata. Its oracle nevertheless required exact dictionary equality. The actor's accurate `application_entry` object and extra capture explanation caused a false negative.

The task now documents flat or nested primary attribution. The checker validates required observations, permits additional explanation, and rejects conflicting direct/nested fields. A regression exercises valid enrichment, wrong attribution, conflicting attribution and wrong capture conditions alongside the existing wrong sample count and protected-capture rejection. Both targeted profile tests passed. The unchanged actor output passed the corrected checker; the initial failure stays in the retained run record. This is a checker correction, not an actor retry.
